# Netflix Movies & TV Shows – Exploratory Data Analysis

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on Netflix Movies and TV Shows to identify trends, patterns, and insights in its content catalogue.

## Project Objectives
- Understand the structure and quality of the dataset.
- Analyze Movies and TV Shows distribution.
- Explore release trends and content additions.
- Identify popular genres, countries, and ratings.
- Analyze movie durations and TV show seasons.
- Discover meaningful patterns through statistical analysis.

## Project Phases
1. Data Understanding
2. Data Quality Analysis
3. Data Cleaning & Preparation
4. Content Type Analysis
5. Release Year Analysis
6. Netflix Content Growth Analysis
7. Genre Analysis
8. Country-wise Content Analysis
9. Ratings Analysis
10. Movie Duration Analysis
11. TV Show Season Analysis
12. Director & Cast Analysis
13. Time-Based Analysis
14. Statistical Analysis
15. Correlation & Relationship Analysis
16. Final Insights & Business Recommendations
17. Project Conclusion

## Tools & Technologies

- Pandas
- NumPy

- Seaborn

## Key Findings
- Movies account for 68.77% of the dataset.
- Drama is the most frequently represented genre.
- The United States and India lead in country-wise content appearances.
- Average movie duration is approximately 104.58 minutes.
- Single-season TV Shows are the most common.

## Dataset
Netflix Movies and TV Shows dataset used for this analysis.
